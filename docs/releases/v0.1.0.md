# v0.1.0 — Home Assistant for the Omarchy bar

Initial release of the native Home Assistant light-control plugin for Omarchy 4.0.

## Highlights

- Live Home Assistant lights grouped by area, with saved area and individual-light selection.
- Individual and area on/off controls, brightness, colors and white temperature on supported lights.
- Browser sign-in, Secret Service credential storage and a shared Python controller.
- A compact bar icon, availability filters and keyboard navigation.
- An `omarchy-ha` launcher for supported `hass-cli` commands.

## Reliability

- Transient token-refresh failures retry automatically and recover controls when the connection is ready.
- Reconnect snapshots remove obsolete lights while preserving newer live events.
- Registry-permission warnings remain visible after connection and refresh recovery.
- Refresh cancellation and stale-session guards protect signout and shutdown.

## Installation

Follow the two-step [installation guide](../../README.md#install): enable the plugin, then install its controller. Omarchy does not run the controller installer automatically.

## Compatibility

Requires Omarchy 4.0, Home Assistant, a Secret Service keyring and the Python dependencies listed in the [README](../../README.md#requirements). The CLI uses its own Python 3.13 environment.

IPC panel requests can open the panel on multiple monitors rather than only the focused monitor. Offline actions are not queued for replay.
